# 场景描述
	 ZLM hook -> 帧解码->格式转换 RGB->放入 inQueue队列->AiTaskQueue从队列取->AiTaskQueue 多线程做 zeroMq + shmmsg 与 python 通信做算法处理 -> python 处理结果写入 shmmsg ->AiTaskQueue 读取结果，放入outQueue-> 格式转换 YUV -> 帧编码-> ZLM 推流 

上述是 custom_module 模块，对 zlm 服务器插入 AI 处理的整个逻辑。

	存在问题：当 AI 处理没有及时启动，或者其他原因（播放停止又启动？），可能会导致帧在  queue 中堆叠，从而导致前端拉流时，播放延迟帧，进而导致直播延迟
