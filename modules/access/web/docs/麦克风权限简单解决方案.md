# 麦克风权限简单解决方案（内网使用）

## 问题
通过 IP 地址访问（如 `http://192.168.x.x:3000`）时，浏览器阻止麦克风权限。

## 最简单解决方案

### 方案 1：Chrome 启动参数（推荐，最简单）

**Windows:**
1. 关闭所有 Chrome 窗口
2. 创建 Chrome 快捷方式
3. 右键快捷方式 → 属性
4. 在"目标"后面添加：
```
--unsafely-treat-insecure-origin-as-secure=http://192.168.x.x:3000 --user-data-dir="C:\temp\chrome-dev"
```
完整示例：
```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --unsafely-treat-insecure-origin-as-secure=http://192.168.x.x:3000 --user-data-dir="C:\temp\chrome-dev"
```

**macOS:**
```bash
# 关闭所有 Chrome 窗口后，在终端运行：
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --unsafely-treat-insecure-origin-as-secure=http://192.168.x.x:3000 --user-data-dir=/tmp/chrome-dev
```

**Linux:**
```bash
google-chrome --unsafely-treat-insecure-origin-as-secure=http://192.168.x.x:3000 --user-data-dir=/tmp/chrome-dev
```

**注意：** 将 `192.168.x.x` 替换为你的实际 IP 地址

### 方案 2：使用 Firefox（更简单）

Firefox 对 HTTP 下的麦克风权限限制较宽松：

1. 访问 `http://192.168.x.x:3000`
2. 点击地址栏左侧的锁图标
3. 点击"权限" → 允许"使用麦克风"
4. 刷新页面即可

### 方案 3：Chrome 标志设置

1. 打开 Chrome，访问 `chrome://flags/`
2. 搜索 `unsafely-treat-insecure-origin-as-secure`
3. 启用该功能
4. 在输入框中添加：`http://192.168.x.x:3000`
5. 重启 Chrome

## 推荐

**最简单：使用 Firefox**，无需任何配置，直接在权限设置中允许即可。

**如果必须用 Chrome：使用方案 1**，创建一个带启动参数的快捷方式。
