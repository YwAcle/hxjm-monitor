# 前端超分结果接入文档

> 适用接口：`POST /chat`  
> Agent 服务地址：`http://<AGENT_HOST>:8002`

## 1. 改动目标

后端完成图片超分后，会在响应的 `data.image_base64` 中返回放大后的图片。前端需要：

1. 使用 `multipart/form-data` 上传图片和提示词。
2. 继续显示后端返回的 `text`。
3. 当 `type` 为 `super_resolution` 时显示结果图片。
4. 提供下载结果图片的按钮。

当前超分提示词必须包含“超分”，例如：

```text
请将这张图片超分2倍
请将这张图片超分4倍
```

## 2. 后端响应

成功响应示例：

```json
{
  "type": "super_resolution",
  "navigate_to": "super_resolution",
  "text": "图片超分完成：1920×1080。",
  "data": {
    "status": "success",
    "description": "图片已完成快速超分",
    "image_base64": "data:image/jpeg;base64,/9j/4AAQ...",
    "original_size": [960, 540],
    "result_size": [1920, 1080],
    "scale": 2.0
  },
  "session_id": "当前会话ID"
}
```

`data.image_base64` 已经包含 `data:image/jpeg;base64,` 前缀，可以直接设置为 `<img>` 的 `src`，不需要再次添加前缀。

## 3. TypeScript 类型

在现有聊天响应类型中增加超分数据：

```typescript
export interface SuperResolutionData {
  status: "success" | "missing_image" | "invalid_image";
  description: string;
  image_base64?: string;
  original_size?: [number, number];
  result_size?: [number, number];
  scale?: number;
}

export interface AgentChatResponse {
  session_id: string;
  type: "normal" | "reid" | "vad" | "super_resolution";
  text: string;
  navigate_to?: string;
  data?: SuperResolutionData | Record<string, unknown>;
}
```

## 4. 上传图片

```typescript
async function requestSuperResolution(
  file: File,
  scale: 2 | 4,
  sessionId: string,
): Promise<AgentChatResponse> {
  const formData = new FormData();
  formData.append("prompt", `请将这张图片超分${scale}倍`);
  formData.append("session_id", sessionId);
  formData.append("file", file);

  const response = await fetch(`${AGENT_BASE_URL}/chat`, {
    method: "POST",
    body: formData,
  });

  const result = (await response.json()) as AgentChatResponse & {
    error?: string;
  };

  if (!response.ok) {
    throw new Error(result.error || `请求失败：HTTP ${response.status}`);
  }

  return result;
}
```

使用 `FormData` 时不要手动设置 `Content-Type`。浏览器会自动生成包含 boundary 的请求头。

## 5. React 展示示例

```tsx
const [loading, setLoading] = useState(false);
const [message, setMessage] = useState("");
const [resultImage, setResultImage] = useState("");

async function handleSuperResolution(file: File, scale: 2 | 4) {
  setLoading(true);
  setMessage("");
  setResultImage("");

  try {
    const result = await requestSuperResolution(file, scale, sessionId);
    setMessage(result.text);

    if (
      result.type === "super_resolution" &&
      result.data?.status === "success" &&
      typeof result.data.image_base64 === "string"
    ) {
      setResultImage(result.data.image_base64);
    }
  } catch (error) {
    setMessage(error instanceof Error ? error.message : "超分请求失败");
  } finally {
    setLoading(false);
  }
}
```

渲染结果：

```tsx
<div>
  {loading && <span>正在处理图片...</span>}
  {message && <p>{message}</p>}

  {resultImage && (
    <div>
      <img
        src={resultImage}
        alt="超分结果"
        style={{ maxWidth: "100%", height: "auto" }}
      />
      <button type="button" onClick={() => downloadImage(resultImage)}>
        下载结果
      </button>
    </div>
  )}
</div>
```

## 6. 下载图片

```typescript
function downloadImage(imageDataUrl: string) {
  const link = document.createElement("a");
  link.href = imageDataUrl;
  link.download = `super-resolution-${Date.now()}.jpg`;
  document.body.appendChild(link);
  link.click();
  link.remove();
}
```

## 7. 错误状态

前端应根据 `data.status` 处理以下结果：

| `data.status` | 含义 | 前端处理 |
|---|---|---|
| `success` | 超分成功 | 显示并允许下载 `image_base64` |
| `missing_image` | 未上传图片 | 显示“请上传需要超分的图片” |
| `invalid_image` | 图片解码失败 | 提示用户重新选择图片 |

只有 `status === "success"` 时才读取 `data.image_base64`。

## 8. 验收步骤

1. 上传一张图片并发送“请将这张图片超分2倍”。
2. 确认对话窗口显示后端返回的 `text`。
3. 确认结果图片显示在对话窗口中。
4. 确认 `result_size` 是原尺寸的约 2 倍。
5. 点击下载，确认得到可正常打开的 JPEG 图片。
6. 分别测试 4 倍、未上传图片和损坏图片。

注意：当前实现使用 Pillow Bicubic 插值放大，不是深度学习超分模型。
